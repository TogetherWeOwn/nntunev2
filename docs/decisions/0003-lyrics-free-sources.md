# Decision 0003 — Lyrics: free sources only (2026-11-03)

Date: 2026-11-03. Provenance: owner spending decision recorded in the
approved programme document (version 1.4).

## Context

Lyrics were once gated on a paid licence. The service is private and
invite-only.

## Decision

No paid licence; free sources for the private instance, in this order:
(1) embedded tags and sidecar files from the curated collection,
(2) a free lyrics API, cached and credited, (3) hide the lyrics tab
when nothing is found.

## Why

Free sources are sufficient for a private instance. A paid licence
returns as a new approval only if the service goes public or
commercial. Search by lyric line may only ever index lyrics already
held from the curated collection. The public-launch re-open trigger is
recorded so the question does not need rediscovery.
