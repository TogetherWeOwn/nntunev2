# Material product decisions

Each record below captures a material owner decision that governs the
product, with context, the actual decision, why, date and provenance.
Decisions are ordered; later records supersede earlier ones where they
conflict, and reversals are preserved. Technical records live in
[docs/adr/](../adr/README.md).

- [0004 — Owner product model](0004-owner-product-model.md) (2026-11-03, final)

Provenance for each record is stated at the file level (date and the
approved document or decision set it came from) so the public text is
self-contained without opening the assignment tracker.
