# Active milestone specifications

This directory holds the active milestone requirements, contracts and
acceptance criteria. Accepted specifications are preserved as written;
proposals are marked as such and do not expand approved scope.

- [M1 exit specification](m1-exit.md) — the invite-gated staging journey
  that gates any production launch consideration (approved 2026-11-03).
- [M1 exit traceability matrix](../m1-exit-traceability.md) — maps each
  M1 exit step to the end-to-end specs that cover it, or records an
  explicit gap. Keep it updated in the same change that moves a spec.
- [Architecture decision records](../adr/README.md) — detailed accepted
  technical decisions (data model, billing, API surface, mirror licences).
- [API surface](../adr/0006-api-surface.md), [API errors](../api-errors.md),
  [API delivery map](../api-delivery-map.md) — native REST and
  Subsonic-compatible contracts.
- [Attribution inventory](../attributions.md) — versioned list of
  third-party data and licence obligations used by the product.

Reading rule: a merged change is not proof of production activation.
Distinguish proposed, approved, implemented and verified states with
dated evidence. See [docs/plans/](../plans/README.md) for the programme
status view.
